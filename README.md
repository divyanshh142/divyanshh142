### 📌 Featured projects

#### 🧮 [ProfitCopilot — AI Profit & Risk Analyzer](https://github.com/divyanshh142)

A multi-tenant AI profitability platform for supply chain decisions, processing **93,000+ SKU-week records**.

- Weekly demand forecasting at **4.07 MAE** and return-risk prediction at **79.1% accuracy** using LightGBM pipelines trained on 177,000+ labelled order lines.
- Natural-language profitability queries through a RAG copilot built on Google Gemini, Spring AI tool-calling, and pgvector similarity search.
- **Stack:** React + TypeScript → Spring Boot API gateway → FastAPI ML microservice → PostgreSQL/pgvector.

#### 🎭 [Emotion Classification with RNNs, LSTMs & GRUs](https://github.com/divyanshh142) *(in progress)*

Benchmarking recurrent architectures for 6-class text emotion classification on `dair-ai/emotion` (16,000+ sentences).

- Lifted accuracy from **33.95%** (best baseline) to **92.1%** with an advanced Bidirectional GRU using 300D embeddings.
- Compared plain RNN, LSTM, and GRU cells in TensorFlow/Keras with tokenization, sequence padding, and class-weight balancing.
- Exported the trained BiGRU and tokenizer as inference-ready artifacts for API integration.
