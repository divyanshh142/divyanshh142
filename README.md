### 📌 Projects

#### 🧮 ProfitCopilot — AI Profit & Risk Analyzer
> `React` · `TypeScript` · `Spring Boot` · `FastAPI` · `PostgreSQL + pgvector` · `LightGBM` · `Google Gemini`

A multi-tenant AI profitability and supply-chain risk platform processing **93,000+ SKU-week records**.

- Weekly demand forecasting at **4.07 MAE** and return-risk prediction at **79.1% accuracy**, via LightGBM pipelines trained on 177,000+ labelled order-line records.
- A **RAG-based AI Copilot** answering natural-language profitability questions, built on Google Gemini, Spring AI tool-calling, and pgvector similarity search.
- Architecture: React/TypeScript frontend → Spring Boot API gateway → FastAPI ML microservice → PostgreSQL with pgvector.

**[→ View repository](https://github.com/divyanshh142)**

#### 🎭 Emotion Classification with RNNs, LSTMs & GRUs *(in progress)*
> `TensorFlow` · `Keras` · `NLP` · `Bidirectional GRU`

Benchmarking recurrent architectures for 6-class text emotion classification on `dair-ai/emotion` (16,000+ labelled sentences).

- Raised accuracy from **33.95%** (best baseline) to **92.1%** with an Advanced Bidirectional GRU using 300D embeddings.
- Compared plain RNN, LSTM, and GRU cells with tokenization, sequence padding, and class-weight balancing to pick the strongest base cell before scaling up.
- Exported the trained BiGRU network and tokenizer as inference-ready artifacts for API integration.

**[→ View repository](https://github.com/divyanshh142)**
